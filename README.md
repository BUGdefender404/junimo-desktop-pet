# 祝尼魔桌面宠物

一只住在小屋里的星露谷祝尼魔，常驻在你的桌面上散步、发呆、冒表情，还会和你的鼠标互动。

## 怎么运行

**方式一（推荐，无需 Python）**：双击 **祝尼魔桌面宠物.exe**，祝尼魔和小屋就会出现在屏幕右下角。

**方式二（脚本版）**：

1. 电脑上需要有 Python 3.9+，并安装依赖（只需一次）：
   ```
   pip install -r requirements.txt
   ```
2. 双击 **启动祝尼魔.bat**。

两种方式只能同时开一个（程序自己会拦重复启动）；配置和待办数据共用。退出：右键点击任务栏右下角的祝尼魔托盘图标 → **退出**。

exe 由 PyInstaller 打包：`pyinstaller --onefile --windowed --name 祝尼魔桌面宠物 --icon 祝尼魔.ico junimo_pet.py`，改完代码想重新出 exe 跑这条命令即可。

## 它会做什么

| 互动 | 效果 |
|---|---|
| 抓起来拖拽 | 可以把它拖到屏幕任何地方（多显示器也行），拖拽时它头顶冒「感叹」 |
| 单击它 | 开心地原地蹦一下，头顶冒「开心」 |
| **双击它** | 弹出/收起**今日待办**面板 |
| 三击**小屋** | 祝尼魔立刻躲进去（直接消失） |
| 双击**小屋** | 祝尼魔立刻从小屋里出来 |
| 鼠标在它旁边停留 | 一半概率凑过来蹭蹭，一半概率害羞地跑开 |
| 拖动小屋搬家 | 祝尼魔会一路小跑跟着走过去（斜着跑回地面线，不瞬移） |
| 电脑闲置 5 分钟 | 头顶冒「无语」 |
| 电脑闲置 10 分钟 | 自己走回小屋，在墙边打瞌睡 |
| **晚上 23:00** | 冒感叹号提醒你休息，然后自动回小屋睡觉 |
| **次日 8:00** | 不用等鼠标动，自动醒来 |
| **全屏视频 / 全屏游戏** | 祝尼魔和小屋自动让位不挡画面，退出全屏自动回来 |
| 有鼠标/键盘动静 | 立刻醒来，头顶冒「感叹」 |
| 平时 | 在小屋附近散步、发呆、蹦跶，偶尔随机冒表情（开心/感叹/无语/困扰/错误） |

## 今日待办

**双击祝尼魔**（或托盘菜单「今日待办」）打开小面板：

- 输入要做什么，点「添加」；每条可以**勾选完成**（会划掉）、点「删」移除
- 勾选「提醒」后，右边的时间框**点开自带日历**，可以选几月几日、设置几点几分：**时间一到（和电脑时钟同步，2 分钟内触发），祝尼魔会跳出来头顶冒「感叹」**，并在它头顶弹出文字气泡告诉你该做什么（每条只提醒一次；数据存在 `todo.json` 里，重启不丢）

> 提示：祝尼魔睡觉时靠在小屋墙边，小屋正面始终可以双击/三击。它躲起来后双击小屋、或托盘菜单「睡觉 / 唤醒」都能让它出来。

小屋也可以用鼠标拖动重新安家，祝尼魔散步的范围会跟着小屋走。它的位置和小屋的位置会自动记住，下次启动还在原地。

## 托盘菜单

右键托盘图标：

- **睡觉 / 唤醒**：手动让它回屋睡觉或叫醒
- **今日待办**：打开 / 收起待办面板
- **隐藏 / 显示小屋**：只留祝尼魔，或把小屋找回来
- **退出**：和它说再见

## 想改行为？

打开 `junimo_pet.py`，文件开头的「可调参数」区域可以改：

- `SCALE`：祝尼魔大小（2 倍 = 96px，改成 3 就是 144px）
- `IDLE_DOZE_S` / `IDLE_SAD_S`：闲置多久睡觉 / 多久先无语
- `NIGHT_START, NIGHT_END`：夜间作息时段（默认 23 点提醒并入睡、8 点自动醒）
- `WANDER_RADIUS`：在小屋周围多大范围散步
- `BUBBLE_POOL`：随机表情出现的权重
- `WALK_SPEED` / `SHY_SPEED`：散步和害羞跑开的速度

## 文件说明

```
祝尼魔桌面宠物.exe   打包好的单文件程序（双击即用，无需 Python）
junimo_pet.py        主程序（全部逻辑都在这一个文件里）
启动祝尼魔.bat       双击启动脚本版（无黑窗口）
祝尼魔.ico           exe 图标
requirements.txt     依赖（PySide6）
素材/                原始素材（exe 和脚本版都要挨着这个文件夹用）
                     程序会生成两个缓存文件：睡觉_已抠图.png、表情X_头像.png（请勿删除）
pet_config.json      自动生成，记录小屋和祝尼魔的位置；删掉可重置位置
todo.json            今日待办数据（自动生成，随面板编辑实时保存）
junimo_debug.log     自动生成的活动日志（记录每次互动和状态切换），可以随时删除
junimo_error.log     只在程序内部出错时生成，欢迎把它发给开发者
```
